No hizo falta equipo especializado. Lo que usamos fue lo siguiente:
\begin{itemize}
\item Un pliego de papel blanco.
\item Una regla de madera de un metro, graduada en centímetros.
\item Lápiz de grafito.
\item Lápices de colores, uno distinto para cada camino.
\item Goma para borrar.
\item Hoja de cálculo para registrar los datos y hacer la gráfica.
\end{itemize}
